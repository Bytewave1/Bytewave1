### dkit

[![PyPI](https://img.shields.io/pypi/v/dkit-cli?label=dkit-cli&color=7c3aed)](https://pypi.org/project/dkit-cli/)
[![Downloads](https://img.shields.io/pypi/dm/dkit-cli?color=7c3aed)](https://pypi.org/project/dkit-cli/)
[![Stars](https://img.shields.io/github/stars/Bytewave1/dkit?color=7c3aed)](https://github.com/Bytewave1/dkit)

An offline CLI for Discord developers: decode snowflakes, translate permission and intent bitfields, look up error codes, scopes, flags and channel types, build invite URLs. No network, no token.

```console
pip install dkit-cli
```

Contributions are welcome: there are [good first issues](https://github.com/Bytewave1/dkit/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) waiting.
